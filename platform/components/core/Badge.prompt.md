Compact tag / count label — quieter than StatusPill (no dot).

```jsx
<Badge tone="accent">LIVE</Badge>
<Badge tone="outline" mono>v2.4.1</Badge>
<Badge tone="caution">3</Badge>
```

Tones: `neutral` `accent` `nominal` `caution` `danger` `outline`. `mono` switches to tabular mono + sentence case for IDs/counts/versions.
